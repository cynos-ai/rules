# 安全合并项目规则入口规格

## 1. 托管区块

当前仓库根 `AGENTS.md` 的可安装内容使用稳定边界：

```markdown
<!-- cynos-rules:begin version=1.2.0 -->
## Cynos Rules
...
<!-- cynos-rules:end -->
```

- begin/end 名称保持稳定，版本只写在 begin 标记；
- 目标项目只复制完整托管区块，不复制 Rules 仓库专用的标题和说明；
- 新增的项目特有规则写在区块之外；如果目标项目已经在区块内加入本地规则，更新时保留在原位置，不自动移动；
- `docs/rules/VERSION` 与区块版本必须在成功更新后保持一致。

## 2. 首次安装

安装 AI 必须先读取目标项目所有可能生效的规则入口并确定当前平台实际使用的入口。

- 入口文件不存在时，可以创建平台原生文件，并写入托管区块；
- 入口文件已存在且没有 Cynos 标记时，在不修改原内容的前提下插入一个完整托管区块；
- 优先追加到不会打断原有 Markdown 结构的位置；不能重排标题、统一格式或顺手修正文案；
- 首次安装始终原样插入最新完整托管区块；发现与 Cynos 内容重复或冲突的项目规则时保留双方原文并报告，不能裁剪托管区块，也不能删除或改写用户内容；
- 多个平台规则文件并存时，只修改确认生效的入口；已有引用链能复用时不重复嵌入。

## 3. 更新有标记的版本

存在且只有一个完整 Cynos 托管区块时：

1. 读取区块声明版本和 `docs/rules/VERSION`；
2. 获取旧版本 tag 中的托管区块和新版本托管区块；
3. 若目标区块与旧版本完全一致，直接替换整个区块；
4. 若目标区块存在本地修改，比较“旧上游 → 新上游”和“旧上游 → 目标本地”，保留本地新增与修改；
5. 实质冲突逐项展示并询问用户；未解决前不更新区块版本或 VERSION；
6. 区块之外内容保持不变。

标记缺失一端、嵌套、重复、版本非法或区块版本与 VERSION 不一致时，不猜测修复，先报告并询问用户。

## 4. 迁移无标记的旧 Cynos 版本

目标项目存在有效 `docs/rules/VERSION`、但平台入口没有标记时：

1. 读取对应 `v<version>` tag 的旧 `AGENTS.md`；
2. 只有与旧上游逐字一致的完整 `AGENTS.md`，或带标题和完整正文、连续且边界清楚的旧 Cynos 章节，才可确认是 Cynos 旧内容；单行或零散语句匹配不能证明所有权；
3. 将已确认的完整旧 Cynos 区段替换为新托管区块；
4. 所有无法与旧上游精确归属的内容保留；
5. 如果保留内容与新托管区块重复或实质冲突，保留双方并列出问题，不能自行裁剪新区块或用户原文；
6. 无法安全划定完整旧 Cynos 边界时，不删除任何原文，先给出迁移计划并等待确认。

无 VERSION 的 v0 或其他未版本化规则默认视为项目内容，不因相似而替换。

## 5. 其他规则文件

`docs/rules/**` 仍使用既有版本差异合并：比较旧 tag、新 tag 和目标本地文件。未知额外文件保留。托管区块只解决平台规则入口的所有权边界，不把整个 `docs/rules/` 变成可覆盖目录。

## 6. 安装提示词与版本

README 安装/更新提示词必须明确：

- 先识别平台入口和已有内容；
- 只复制根 `AGENTS.md` 中的托管区块；
- 新安装保留入口原文；
- 有标记版本按区块更新；
- 无标记旧 Cynos 版本按 tag 精确识别；
- 本地修改使用三方差异合并；
- 标记或所有权不明确时停止询问；
- 成功后再同步区块版本与 `docs/rules/VERSION`。

当前版本更新为 `1.2.0`，合入 `main` 后创建 `v1.2.0` tag。

## 7. 验收条件

- **AC-MARKER-01**：根 AGENTS 包含唯一、完整、带 `1.2.0` 的托管区块；
- **AC-INSTALL-01**：首次安装只新增托管区块，不改写原规则入口内容；
- **AC-UPDATE-01**：未修改的旧 Cynos 区块可以整体替换，本地修改通过三方差异保留；
- **AC-LEGACY-01**：无标记旧 Cynos 内容只有精确匹配时才可替换，v0 默认保留；
- **AC-FAILSAFE-01**：重复、损坏、版本不一致或归属不明时停止询问；
- **AC-PLATFORM-01**：AGENTS、CLAUDE 等入口共用同一安全合并规则，不重复嵌入；
- **AC-FILES-01**：docs/rules 仍执行版本差异合并，额外文件不被删除；
- **AC-VERSION-01**：VERSION、区块版本、Changelog 和发布 tag 一致为 `1.2.0`；
- **AC-READER-01**：无上下文 AI 能正确处理首次安装、普通升级、本地修改、无标记旧版和损坏标记五种情况。
