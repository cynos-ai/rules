从旧、新正式 tag 的规则文件集合建立上游差异清单，不以 Changelog、旧上游与本地差异、校验和列表或本次准备修改的文件代替。逐项确定合并结果及未解决冲突；涉及删除、改名时仍保护本地和未知内容，不引入持久 Manifest。
