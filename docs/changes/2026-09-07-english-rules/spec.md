# 英文单一规则正文

八份规则及根 AGENTS 托管区块使用英文，同步两版 README 和 PROJECT 的语言说明。规则职责、优先级、路径、标记、版本格式、场景字段与状态不变；不改区块外仓库说明、历史需求或阅读副本。英文标题同步内部链接，已有被引用的中文完成边界锚点保留为兼容标识，不是另一份中文正文。

翻译必须保留条件、禁止事项、例外、用户确认、失败与恢复要求。尤其不能将英文正文误解为默认英文回复，不能将语言差异视为可覆盖本地内容的授权。中文示例中的自然语言翻译为英文；机器标识按原约定保留。

用户确认的补充：针对执行中未询问就升版的问题，明确保留本地内容不等于解决实质冲突；存在冲突时先展示差异、推荐方案并等待用户选择，此前不写项目、不升版、不报告完成。兼容的本地补充不因此被误判为冲突。入口与规则文件采用相同判据：翻译或文本移动造成行重叠时，先比较旧上游、新上游与本地含义；确认兼容则在临时位置重建合并，原样、原位保留本地补充后继续。要求矛盾或无法确认兼容时仍先询问，不能凭文本合并命令失败就一律要求用户决定。这是澄清已有边界，不改变规则优先级或引入自动执行机制。

验收：逐条中英语义核对无遗漏或强度变化；格式与链接有效；独立读者能正确理解关键边界。首次安装、从中文旧版升级、只读检查和实质冲突复测，核对完整合并、本地保护和实际内容验证早于两处版本写入。中文用户面对英文规则仍用中文回复。失败与未验证范围保留，不以最终 hash 或翻译静态通过代替执行验收。
